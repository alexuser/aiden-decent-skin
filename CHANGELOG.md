# Changelog

## 0.1.0-alpha.1

Initial developer preview: independently selectable Aiden skin with pinned DSx2
library dependency and isolated skin preferences. Native profile browsing,
private recipe drafts, operating/mode screens, pressure/flow graphs, preparation
workflows and native utility routes. Missing data remains unavailable.

Includes live ratio updates without precision loss, safe draft cancellation,
legacy native-home return, and recoverable dependency/startup failures. No DSx2
files, application launcher, profiles or machine settings are shipped.

Validated with isolated host tests and offline physical-tablet navigation.
Live machine operation, transport timing and app-update survival remain untested.
